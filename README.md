 Paradise Nursery Shopping Application

Project Name: Paradise Nursery

Description:
A front-end React application for Paradise Nursery that allows users to browse houseplants, add them to cart, and manage cart quantities.

 Features:
- Landing page with company info and Get Started button
- Product listing page with 18 plants in 3 categories
- Shopping cart with quantity controls
- Redux for state management
- Deployed via GitHub Pages
How to run:
npm install
npm run dev
